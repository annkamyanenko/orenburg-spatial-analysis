# Пространственная аналитика Оренбурга

Откройте [index.html](index.html) в Chrome, Edge или Firefox. Данные Leaflet и обе векторные подложки включены в комплект. Интернет нужен для Montserrat и обзорной спутниковой мозаики NASA GIBS. При недоступности тайлов выберите локальную подложку или режим без подложки. Разрешение мозаики недостаточно для рассмотрения отдельных зданий.

Переключайте разделы сверху, затем показатель кварталов и слои справа. Ползунок меняет непрозрачность слоя. Щелчок по кварталу открывает его характеристики. Щелчок по столбцу диаграммы выделяет соответствующий класс, повторный щелчок снимает выделение. Кнопки на краях панелей и над картой управляют их видимостью. «Методология» открывает правила интерпретации.

## Данные и повторное использование

Источник — выгрузка практики № 2 `data/orenburg/results/8d64d1206ffa9bd94e07cad3`. Для практики № 3 используйте исходные GeoJSON, CSV, матрицу Parquet и манифест. Веб-файл содержит только поля для визуализации и округлённые координаты. Подготовка проверяет манифест, совпадение полей и идентификаторов CSV и GeoJSON, доли, знаменатели, норму спроса и баланс городских и групповых итогов. Исходная аналитика при сборке не пересчитывается.

Для повторной подготовки выполните из корня проекта:

```powershell
& .venv/Scripts/python.exe -B dashboard/prepare.py
```

Для сборки из другого локального запуска передайте путь к каталогу, имя которого совпадает с полем `signature` в его манифесте. Для просмотра версии, сохранённой в Git, сборка и исходная выгрузка не требуются.

```powershell
& .venv/Scripts/python.exe -B dashboard/prepare.py --source "data/orenburg/results/<ключ>"
```

Для проверки по HTTP можно запустить `& .venv/Scripts/python.exe -m http.server 8000 --bind 127.0.0.1 --directory dashboard` и открыть `http://127.0.0.1:8000/`. Для будущей публикации пригодна статическая папка с `index.html`, CSS, JavaScript, `data.js` и лицензией Leaflet. Все пути относительные, серверный код отсутствует. Публикация выполняется отдельно по согласованию.

## Особенности интерпретации

- В выгрузке непривязанные кварталы имеют ноль в `reachable_area_share`. Общегородская медиана показана как в исходном отчёте. Карта, диаграмма и карточка квартала обозначают такой случай как «Нет данных». `reachable_bound_area_share` использует только площадь привязанных кварталов.
- Общегородская обеспеченность делит площадь всего инвентаря рекреационных объектов на население города. Сравнение групп делит площадь пересечений объектов с кварталами соответствующей группы на её население. Эти величины отличаются из-за охвата.
- Пустая стоимость маршрута означает отсутствие подтверждённого результатом маршрута в заданном пороге или недостаток входных данных. Доли удовлетворения относятся к сценариям распределения и могут быть нулевыми при доступной исходной информации.
- В обзорной карточке показана площадь нарезанных кварталов, а контур города служит пространственной рамкой. Неполная верификация контура отмечена в интерфейсе.

При согласовании публикации проверьте, что `origin` указывает на ваш репозиторий. В исходном шаблоне есть workflow для публикации документации в ветку `documentation` при отправке изменений в `main` или `develop`. Для GitHub Pages с дашбордом потребуется выбрать отдельный источник публикации, содержащий статический комплект из `dashboard/`.
